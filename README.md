# Awesome Claude Video Skills

[中文](README.zh-CN.md)

Open-source skills and toolkits that let **Claude Code, Codex and other coding agents make video**: HyperFrames, Remotion, motion graphics, editing, explainers, avatars. 499 repos, each one read and security-graded by [Agent Skills Hub (agentskillshub.top)](https://agentskillshub.top).

Live page with filters: **[https://agentskillshub.top/best/claude-video-skills/](https://agentskillshub.top/best/claude-video-skills/)** · refreshed every 8 hours

## Which one to install

We ran 16 of these end to end (16 gave a result). This is what we would pick; the [full test](#tested) is below.

- 🥇 **For a finished film fast: [explainroo](https://github.com/vincentsch/explainroo)**  
  Two minutes from brief to a film with sound, the quickest of the sixteen, and it does not look like the default.
- 🥈 **For a film with one idea running through it: [onetake](https://github.com/feitangyuan/onetake)**  
  A single drop of water carries all five lines with no cuts. For a fuller, illustrated picture the one to watch is motion-video-kit, if you can wait 22 minutes.
- 🥉 **To build your own design in Remotion: [skills](https://github.com/remotion-dev/skills)**  
  Remotion's own skills: reliable rendering in 4.5 minutes. The film it makes unprompted is close to the default, so bring your own design direction.

**Know before you pick:** hyperframes (the most-starred renderer here took 23.5 minutes on a 15-second brief); motion-graphics (built for talking-head footage, which this brief did not have).

Whichever you pick: you may not need one for a simple promo. Claude Code with no skill made a film that passed every check in 4.4 minutes. A skill earns its place with a look, a workflow, or footage to edit.

*Not ranked: all 16 skills, and Claude Code with no skill, passed the same four checks (a playable file, the length and size asked for, all five lines of copy readable, a picture that moves). The table is in order of time taken. Whether a film looks like the default or has a look of its own was judged by eye; watch them and judge for yourself.*

## How a repo gets on the list

1. It makes or edits video or motion graphics. A 3D web page or a prompt collection does not count. The few entries under *Scripts & learning* come before the video (screenwriting, shot analysis) and are listed by the maintainer's choice.
2. An agent operates it: a skill, a plugin, an MCP server, or a toolkit written for the agent.
3. It has a README. Without one it cannot be graded.
4. At 50 stars or more it is listed on topic alone. Under 50 it must also clear a README quality bar (shows the result, one-command start, a concrete outcome, complete docs), and have 5 stars unless it names Claude Opus 5.5.

The questions are answered by a decision model reading each README, not by hand. A repo near a cut-off can land on either side; open an issue if one is misfiled.

## 🧪 Tested end to end

On 2026-10-11 we had 16 of these skills make the same film in a throwaway sandbox, driven by Claude Code (Claude Opus 5.5): a 15-second promo for a made-up app, with five fixed lines of on-screen copy, at 1920 x 1080 and 30 frames per second, on a machine with no API keys for video, image or voice models. Claude Code with no skill made it too. Four things were checked from each file: it plays, it is the length and size asked for, every line of copy can be read in frames sampled twice a second, and the picture moves. How good a film looks is not scored. The films are below.

**What we found:** All 16 rendered a film that passed all four checks, with no line of copy missing and nothing added, and so did Claude Code with no skill, in 4.4 minutes. None needed a paid model for this brief. What differs is time (2.0 to 23.5 minutes), sound (9 of 16 added it), and the look: 6 came out close to the no-skill film (deep teal water, waves, white centred type) and 10 have a look of their own, by our eye.
